# План: личный дашборд «Экономика сегодня»

Статический сайт на HTML + CSS + обычном JavaScript. Без фреймворков и сборки.

## Как устроено

```
Браузер (index.html)
 ├─ каждые 60 с ─► Cloudflare Worker ─► Yahoo Finance (индексы, валюты, сырьё, крипта, акции)
 └─ при открытии ─► data.json (лежит рядом с сайтом)

GitHub Actions, раз в день ─► FRED, ECB, NBP, Eurostat/GUS, Nasdaq, RSS ─► data.json ─► GitHub Pages
```

### Почему не Twelve Data / Finnhub / CoinGecko

Проверил их бесплатные тарифы (18.11.2026):

- **Twelve Data free**: нет индексов S&P 500 / Nasdaq / Dow и WIG20, Brent и Orlen / CD Projekt только на платных тарифах.
  Лимит 8 запросов в минуту. На 23 актива раз в минуту нужно в 3 раза больше.
- **Finnhub free**: только котировки акций США, индексов и Варшавской биржи нет.
- **CoinGecko без ключа**: при проверке после пары перезагрузок страницы ответил «слишком много запросов» (429),
  крипта показала «нет данных». Yahoo отдаёт биткоин и эфир так же полно, поэтому всё берём из одного источника.

**Yahoo Finance** покрывает всё из списка, включая WIG20 и польские акции, без ключа.
Но браузер не пускают к нему напрямую (нет CORS).
Поэтому нужен маленький бесплатный посредник: **Cloudflare Worker**, один файл `worker/worker.js`, вставляется в панели Cloudflare.
Yahoo — неофициальный источник. Если он сломается, источник меняется в одном месте (`worker/worker.js`).

Плюс: в браузере нет ни одного ключа, светить нечего. Все ключи только в GitHub Secrets для ежедневного сбора.

## Аккаунты и ключи

| Что | Зачем | Цена | Когда понадобится | Куда вставить |
|---|---|---|---|---|
| GitHub | хранит код, хостинг (Pages), ежедневный сбор (Actions) | бесплатно | шаг «Деплой» | — |
| Cloudflare | Worker-посредник для котировок | бесплатно, без карты | шаг «Деплой» | адрес Worker → `js/config.js` (это не секрет) |
| FRED API key | ставка ФРС, инфляция и безработица США | бесплатно | шаг 4 | GitHub Secret `FRED_API_KEY` |

Без ключа: Yahoo, ECB, NBP, Eurostat, GUS, Nasdaq, RSS.

## Шаги

1. ✅ План и список ключей (этот файл).
2. ✅ Таблица «Рынки сейчас»: 11 активов, изменения за 1 ч / день / неделю / месяц / год, мини-график, тёмная тема, телефон. Локальный запуск `node server.js`.
3. ✅ «Крупные компании» + «Топ-5 растут / падают за день».
4. ✅ Ежедневный сбор через GitHub Actions → `data.json`: ставки и инфляция, даты заседаний.
5. ✅ «Что ждать»: календарь на 7 дней — решения центробанков, важная статистика США и еврозоны, отчёты крупных компаний.
6. ✅ «Главное за день» (новости) и «Слово дня».
7. Деплой: GitHub Pages + Cloudflare Worker, README с пошаговой инструкцией, проверка безопасности.

## Правила данных

- Только реальные источники. Нет ответа → «нет данных».
- Старое значение показываем только с пометкой «не обновилось, данные на ЧЧ:ММ».
- Если биржа закрыта, изменение за 1 час не считаем и пишем «биржа закрыта».
- Пометка о задержке: бесплатные котировки могут отставать до ~15 минут, Варшавская биржа — всегда на 15 минут.
- Внизу сайта: «Это не инвестиционная рекомендация».

## Решения

- Мини-графики рисуются вручную через SVG (около 40 строк), без библиотеки: для маленьких линий Chart.js/uPlot избыточны.
  Если понадобится большой график по клику, подключим uPlot.
- Мини-график показывает последний месяц: дневные цены закрытия и текущую цену.
- «День» для индексов, валют, сырья и акций — к цене закрытия прошлого торгового дня; для криптовалют — за последние 24 часа.
- Для WIG20 Yahoo не отдаёт дневную историю: посредник собирает её из часовых цен за год.
- Ставка ЕЦБ — ставка по депозитам (DFR), ЕЦБ сам называет её главной.
- Инфляция еврозоны — Eurostat `prc_hicp_minr`: прежний ряд ЕЦБ (ICP) закрыт в 2026 году.
- Инфляция Польши — GUS (API DBW, переменная 305, раздел 1698), а не HICP Eurostat:
  в польских новостях называют именно цифру GUS.
- Инфляция США — CPI без сезонной поправки (CPIAUCNS), как в новостях.
- nbp.pl закрыт защитой от роботов (Incapsula), static.nbp.pl — нет. Ставка NBP берётся из XML,
  даты заседаний RPP раз в год вручную переносятся в `js/config.js`.
- Если источник не ответил, в data.json остаётся прошлое значение с прошлой датой проверки,
  сайт помечает его как устаревшее через 2 дня. Workflow при этом падает, и GitHub присылает письмо.
- Календарь «Что ждать» (сборщик берёт 14 дней вперёд, сайт показывает 7):
  - статистика США — календарь выпусков FRED (`releases/dates`), только важные выпуски: CPI, рынок труда, ВВП, PCE, розничные продажи;
  - статистика еврозоны — тот же JSON, который грузит страница календаря Eurostat (`/o/calendars/eventsJson`),
    только первая и итоговая инфляция, первая оценка ВВП, безработица. Официального API у календаря нет;
  - отчёты компаний — календарь Nasdaq (`api.nasdaq.com/api/calendar/earnings`, без ключа, неофициальный):
    компании из нашего списка и все дороже $200 млрд. Finnhub не нужен.
  - GUS публикует будущие даты только в PDF, у GPW нет открытого календаря — польской статистики
    и отчётов польских компаний в календаре нет, на сайте это написано.
- Новости — бесплатно, без пересказа ИИ (решение владельца): RSS на русском — Investing.com «Экономика» и
  «Экономические показатели», DW «Экономика». До 5 самых свежих за последние 36 часов, не больше 2 из одной ленты.
  Заголовки как в источнике, у DW ещё и описание. Ссылки только http(s).
  Если часть лент не ответила, показываем остальные и пишем «нет данных» про молчащие.
- «Слово дня» — собственный словарь `js/words.js` (78 понятий), выбирается по дате, по кругу. Сборщик не нужен.
