# Экономика сегодня

Личный дашборд по мировой экономике: рынки, валюты, сырьё, криптовалюты, крупные компании,
ставки центробанков и инфляция.
Простой статический сайт: HTML, CSS и обычный JavaScript, без сборки.

План и список нужных ключей — в [PLAN.md](PLAN.md).

## Запустить у себя на компьютере

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```
node server.js
```

Откройте http://localhost:8080 в браузере.

Цены обновляются раз в минуту, пока вкладка открыта.

## Опубликовать в интернете

Сайт живёт на GitHub Pages, посредник цен — на Cloudflare Workers. Оба бесплатные, карта не нужна.
Займёт примерно полчаса. Ключи и токены вводятся только в настройках GitHub — в коде их нет.

### 1. GitHub: репозиторий и сайт

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Справа вверху «+» → New repository. Имя, например, `ekonomika`, видимость **Public**
   (бесплатный GitHub Pages работает только для публичных репозиториев).
   Ничего не добавляйте (без README и .gitignore) → Create repository.
3. Отправьте код из папки проекта — подставьте своё имя на GitHub:

   ```powershell
   git remote add origin https://github.com/ВАШЕ-ИМЯ/ekonomika.git
   ```

   ```powershell
   git push -u origin main
   ```

   При первом push откроется окно входа в GitHub.
4. В репозитории: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
5. Settings → Secrets and variables → Actions → New repository secret:
   имя `FRED_API_KEY`, значение — ваш ключ FRED (как получить — ниже, в разделе про ежедневный сбор).
6. Вкладка Actions → «Обновить данные» → Run workflow. Через пару минут сайт откроется по адресу
   `https://ВАШЕ-ИМЯ.github.io/ekonomika/`. Цен пока не будет — для них нужен шаг 2.

### 2. Cloudflare: посредник цен

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up).
2. Слева Workers & Pages (Compute) → Create → Worker → шаблон «Hello World».
   Имя, например, `ekonomika-quotes` → Deploy.
3. Edit code → удалите всё, вставьте содержимое файла `worker/worker.js` → Deploy.
4. Скопируйте адрес Worker — вида `https://ekonomika-quotes.ВАШ-ПОДДОМЕН.workers.dev`.
   Откройте `адрес/health` — должно быть `{"ok":true}`.
5. Впишите адрес в [js/config.js](js/config.js), в строку `quotesProxy` (без `/` в конце), и отправьте изменение:

   ```powershell
   git commit -am "Адрес посредника цен"
   ```

   ```powershell
   git push
   ```

   Сайт опубликуется заново сам, через минуту-две цены появятся.

Бесплатно Worker выдерживает 100 000 запросов в день. Одна открытая вкладка тратит около 1 400 в час,
так что для личного пользования хватает с запасом.
Если поменяете `worker/worker.js`, вставьте его в Cloudflare заново (шаг 3).

### 3. Алерты в Telegram (по желанию)

Раз в час GitHub проверяет: отвечает ли посредник и Yahoo, открывается ли сайт, свежие ли данные
(`.github/workflows/health.yml`). Если что-то не так или не удался ежедневный сбор, GitHub пришлёт письмо,
а если настроить Telegram — ещё и сообщение туда.

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя.
   Он пришлёт токен бота — строку вида `123456:ABC...`.
2. Напишите своему новому боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/botТОКЕН/getUpdates` (вместо ТОКЕН — токен из шага 1)
   и найдите `"chat":{"id":` — это число и есть ваш chat id.
4. В репозитории Settings → Secrets and variables → Actions добавьте два секрета:
   `TELEGRAM_BOT_TOKEN` (токен) и `TELEGRAM_CHAT_ID` (число).
5. Actions → «Проверить сайт» → Run workflow — проверка должна пройти зелёной.

## Ставки, календарь и новости: ежедневный сбор

Ставки, инфляцию, безработицу, даты заседаний, календарь событий «Что ждать» и новости собирает скрипт `scripts/update-data.mjs`
и сохраняет в `data/data.json`. В интернете его раз в день запускает GitHub Actions
(`.github/workflows/update-data.yml`), сайт просто читает готовый файл.

Для данных США нужен бесплатный ключ FRED:

1. Зарегистрируйтесь на [fred.stlouisfed.org](https://fred.stlouisfed.org).
2. My Account → API Keys → Request API Key. Ключ — строка из 32 символов.
3. Для запуска у себя: скопируйте `.env.example` в `.env` и вставьте ключ после `FRED_API_KEY=`.
   Файл `.env` не попадает в git.
4. Для GitHub: репозиторий → Settings → Secrets and variables → Actions → New repository secret,
   имя `FRED_API_KEY`, значение — ключ.

Собрать данные вручную у себя:

```
npm run update-data
```

Если какой-то источник не ответил, скрипт сообщит об этом и завершится с ошибкой,
а в `data.json` останется прошлое значение. Сайт пометит его «⚠ не обновлялось с …», если ему больше двух дней.

**Раз в год:** даты заседаний Нацбанка Польши (RPP) нужно перенести в `js/config.js`, раздел `nbpMeetings`.
Сайт nbp.pl закрыт от программ-роботов, поэтому автоматически их взять нельзя.
Расписание на следующий год NBP публикует в конце года на
[странице расписания](https://nbp.pl/polityka-pieniezna/rada-polityki-pienieznej/harmonogram-rpp/).
Пишите второй день каждого заседания: в этот день объявляют решение.

## Добавить актив или компанию

Всё перечислено в [js/config.js](js/config.js):
`markets` — таблица «Рынки сейчас», `companies` — «Крупные компании».
Из `companies` же считаются «Топ-5 растут» и «Топ-5 падают».

1. Найдите актив на [finance.yahoo.com](https://finance.yahoo.com).
   Код стоит в адресе страницы, например `finance.yahoo.com/quote/PKN.WA` → `PKN.WA`.
2. Скопируйте любую строку в нужном списке и поменяйте поля:

```js
{ group: "Индексы", name: "mWIG40", hint: "40 средних компаний Варшавской биржи", symbol: "MWIG40.WA", kind: "index" },
```

- `group` — в какой группе таблицы показывать;
- `name` — название;
- `hint` — подсказка в одну фразу под названием;
- `symbol` — код с Yahoo Finance;
- `kind` — `index` (без валюты), `fx` (курс валют), `commodity` (сырьё), `crypto`, `stock` (акция).

Пример компании: `{ group: "Польша", name: "KGHM", hint: "Добывает медь и серебро", symbol: "KGH.WA", kind: "stock" },`

3. Сохраните файл и обновите страницу.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html` | разметка страницы |
| `css/style.css` | оформление, светлая и тёмная тема, вид на телефоне |
| `js/config.js` | списки активов и компаний, настройки |
| `js/app.js` | загрузка цен, расчёт изменений, мини-графики, вывод всех блоков |
| `js/words.js` | словарь для «Слова дня» — чтобы добавить понятие, допишите строку в конец |
| `worker/worker.js` | посредник к Yahoo Finance (в интернете работает как Cloudflare Worker) |
| `server.js` | локальный запуск: отдаёт сайт и работает как посредник |
| `scripts/update-data.mjs` | ежедневный сбор ставок, инфляции, календаря и новостей |
| `data/data.json` | результат ежедневного сбора, его читает сайт |
| `.github/workflows/update-data.yml` | раз в день запускает сбор данных |
| `.github/workflows/pages.yml` | публикует сайт на GitHub Pages после каждого изменения и каждого сбора |
| `.github/workflows/health.yml` | раз в час проверяет посредника, сайт и свежесть данных, шлёт алерты |

Почему нужен посредник: Yahoo Finance не разрешает браузеру брать данные напрямую.
Поэтому сайт спрашивает посредника, а посредник — Yahoo.

## Откуда данные

- Цены: Yahoo Finance. Бесплатно, без ключа.
  Цены могут отставать до ~15 минут, Варшавская биржа — всегда на 15 минут.
- Ставки: ФРС — FRED, ЕЦБ — ECB Data Portal, Нацбанк Польши — static.nbp.pl.
- Инфляция: США — FRED (данные BLS), еврозона — Eurostat, Польша — GUS. Безработица США — FRED (BLS).
- Даты заседаний: официальные календари ФРС и ЕЦБ, для NBP — список в `js/config.js`.
- Календарь «Что ждать»: статистика США — календарь FRED, еврозоны — календарь Eurostat,
  отчёты компаний — календарь Nasdaq (только компании с американских бирж).
  Какие публикации показывать, задано в начале `scripts/update-data.mjs` (`US_RELEASES`, `EU_RELEASES`).
- Новости: RSS-ленты Investing.com и DW на русском (список `NEWS_FEEDS` в `scripts/update-data.mjs`).
  Заголовки показываются как в источнике, без пересказа.
- «Слово дня»: собственный словарь сайта, `js/words.js`.
- Если источник не ответил, на странице будет «нет данных».
  Если не обновилось, но старая цена есть, рядом будет «⚠ не обновилось · данные на ЧЧ:ММ».

Это не инвестиционная рекомендация.
